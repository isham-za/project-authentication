Core Security Controls Implemented
Strong Password Hashing

NIST-approved PBKDF2 with SHA-256 algorithm and automatic per-user salt. Plaintext passwords are never stored or logged.

CSRF Protection

Synchronizer Token Pattern with HttpOnly and SameSite cookie policies defending all state-changing POST requests.

XSS Auto-Escaping

Django template engine automatically sanitizes context variables, blocking reflected and stored script execution.

SQL Injection Defense

Django ORM uses strict parameter binding and parameterized queries, preventing SQL syntax escaping payloads.

Brute-Force & Rate Limiting

Monitors consecutive failed attempts per IP/username, applying temporary cooling restrictions to thwart brute force.

Secure Session Management

HttpOnly session cookies, SameSite restrictions, session cycling on login to stop fixation, and complete session flushing on logout.
